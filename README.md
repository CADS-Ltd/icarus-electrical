# Icarus Electric: website design concepts

Three homepage concepts for Icarus Electric (Kevin Peck), based on the sites the client likes: eliteelectrical.co.uk and efixx.co.uk.

| Concept | Folder | Direction |
| --- | --- | --- |
| 1. Eclipse | `concept-1-eclipse/` | Dark and premium, closest to Elite Electrical |
| 2. Daylight | `concept-2-daylight/` | Light and friendly, focused on getting enquiries |
| 3. Live Wire | `concept-3-live-wire/` | Bold and media-led, closest to eFIXX |

`index.html` is the landing page that links to all three. Each concept is a single self-contained HTML file, with shared images in `assets/`.

Anything shown like `[this]` is a placeholder (phone, email, service area, reviews, project photos). The forms are for display only.

## Hosting on GitHub Pages

Settings → Pages → Deploy from a branch → pick the branch and `/ (root)`. The site then appears at `https://jbarrett7.github.io/icarus-electrical/`.
